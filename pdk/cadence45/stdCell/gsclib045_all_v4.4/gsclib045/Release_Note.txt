II. Recommended Directory Structure and Standard Cell Library Location:

   <Project Root directory = $PROJECT>
    |
    |-- TECH                   (PDK Technology)
    |   |-- GPDK045            
    |       |-- gpdk045        (A symbolic link to specific PDK version )
    |       |-- gpdk045_v_3_5  (A specific PDK version <=> ***Result of unpacking the PDK tarball***)
    |
    |-- LIBS                   (Standard cell library database)
    |   |-- GPDK045            
    |       |-- gsclib045      (A symbolic link to a specific version, Eg: gsclib045_v4.1 )
    |       |-- gsclib045_v4.1 (A specific std.Cell database version <=> ***Result of unpacking std.Cell tarball***)
    |
    |-- DESIGNS                (Design databases that are subject to PDK dependence )
    |   |-- GPDK045
    |       |--<FRACNPLL>      (Eg: An IC design called "FRACNPLL" )
    |           |-- cds.lib
    |           |-- docs
    |           |-- digital
    |           |-- oa
    |               |-- zambezi45     (Virtuoso design library)
    |               |-- zambezi45_sim (Virtuoso test-bench library)
    |
    |-- WORK                  (Work-space or Work-area)
    |   |-- <zambezi45>       (Eg: A work-space for 'zambezi45' design <=> A dedicated area for launching design tool/s)
    |        |-- Makefile
    |        |-- project.cshrc
    |        |-- .cdsinit
    |        |-- cds.lib
    |  
    |-- <bin>
    |-- <etc>
    |-- <doc>
    |-- <setup>
