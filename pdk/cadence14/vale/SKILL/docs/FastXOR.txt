VALE Framework Component Module:
--------------------------------
   PVS FastXOR, FastXOR

Description:
------------
   Runs the PVS FastXOR utility and outputs the results to the Annotation
Browser for review.

Dependencies:
-------------

Input Requirements:
-------------------
   1. PVS added to the PATH environment variable
   2. An open cellview in Virtuoso Layout

Output:
-------
   Markers are output to the Annotation Browser.  Window -> Assistants ->
Annotation Browser.

Implementation Details:
-----------------------
   FastXOR assumes the Virtuoso view name is always "layout".
