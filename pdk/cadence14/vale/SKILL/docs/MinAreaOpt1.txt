VALE Framework Component Module:
   Optimize 1x Minimum Area, MinAreaOpt1 

Description:
   This Component Module runs the best-in-the-industry pattern analysis with hotspot fixing to create design improvements to minimum area shapes. This module is an example of an area-driven minimum area optimization. The solution to the minimum area issue may be specified for any width! 

   In this example, it looks for M1 shapes that have an area less than 0.006176 um^2, and a length < 193nm, and a width >= the length. If the pattern is matched, then optimization will occur in such a way as preserve the required spacing between two metal shapes, both with minimum area problems.

Setup Requirements:
   - Include/MinAreaOpt1_V01/*.conf file: LPA configuration file: set variables compModName, compModVers, and layerOrder. Everything else should stay the same.
   - Include/MinAreaOpt1_V01/*.lpainit: Set the jobname to match the jobName in the .conf file, everything else should stay the same, unless a non-local run is needed.
   - Include/MinAreaOpt1_V01/*.preprocess.tcl: check the path in lpaPreProcessEclair, that it is accessible and correct.  Use "which eclair" to set this path.
   - Include/MinAreaOpt1_V01/*.preproc.xml: This is the topological (squish) pattern deck, part 1. It locates the area-based minimum area cases.
   - Include/MinAreaOpt1_V01/*.xml: This is a secondary pattern deck, part 2, for generating design shapes with the "overlay_scanline_range" parameter.
   - Include/MinAreaOpt1_V01/*.streamout_map: A layer map file for writing data from Virtuoso for use in CPA
   - Include/MinAreaOpt1_V01/*.cpa_map: A layer map file for reading layout data into CPA for part 1 of pattern matching, and mapping layers out of CPA to LPA
   - Include/MinAreaOpt1_V01/*.lpa_map: A layer map file for reading layout data into LPA for part 2 of pattern matching, and mapping layers out of LPA
