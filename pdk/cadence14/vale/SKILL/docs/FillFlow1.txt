VALE Framework Component Module:
   Fill Flow 1

Description:
   This Component Module provides an example of a design finishing flow, using a sequence of pre-defined component modules.

   In particular, this flow runs Add Trim Shapes, Insert WSP Fill, M1 coloring, Standard Fill, and M1 coloring.
