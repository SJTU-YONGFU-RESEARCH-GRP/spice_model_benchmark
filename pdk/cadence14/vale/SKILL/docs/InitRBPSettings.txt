VALE Framework Component Module:
   Initialize Region-driven RBP Flow

Flow Example: VVF_Testcase_Lib, level_shifter2
   1. Open Schematic, Launch Layout EXL, Create New
   2. Open VALE -> Region-driven RBP Flow -> Initialize...
   3. Tear-off the Region-driven RBP Flow menu
   4. Generate All From Source (from the VALE menu), Shift-f
   5. Load Row Templates, open; Load Gate WSP Templates, open
   6. Optimize PCell Parameters
   7. Create Row Regions, in the form that opens, select the Row tab.  Select the 528nm high, 5 fin row style.  Go to the Cereate tab, select region.  Enter the coordinates of the region, select update to view it, and insert to create the rows.  Example: first region at: 0,0 1.456,1.056; second region at 1.83,0 2,2.112.
   8. Select left row region, Create Gate WSP Regions, select bottom WSP.
   9. Select right row region, Create Gate WsP Regions, select top WSP.  At this point use the the VALE -> Utilities -> Grid Tool, with X step set to 0.01 and Y step set to 0.528.  Select "Set Grid" and check the Display Grid box.
  10. Select the thick oxide devices, with Boundary set to rowRegion0 and Select Only checked, and select "Run Placement"
  10. Select the thin oxide devices, with Boundary set to rowRegion1 and Select Only checked,  and select "Run Placement"
  11. Manually adjust devices.  Select instances, run Abut Selected Instances
  12. Select Delete Inactive Poly WSPs
  13. Open VALE -> Utilities -> Snap Instances to Poly WSP Grid
  14. Continue to follow the flow on the VALE -> Region-drive RBP Flow 

Description:
   This Component Module initializes a particular design flow. For example:

         envSetVal("layout" "snapWireGrid" 'cyclic "Snap Pattern")
         envSetVal("layoutXL.APAssist" "WSPAware" 'boolean t)
         envSetVal("layoutXL.placement" "vcpCellBoundaryLPPs"
            'string "(Active drawing)")
         envSetVal("layoutXL" "lxGenerateInBoundary" 'boolean nil)
         envSetVal("layoutXL" "lxGenerateInBoundary" 'boolean nil)
         envSetVal("layoutXL" "initCreatePins" 'boolean nil)
         envSetVal("layoutXL" "initEstimateArea" 'boolean t)
         envSetVal("layoutXL" "initCreateSnapBoundary" 'boolean nil)
         envSetVal("layoutXL" "initCreateBoundary" 'boolean t)
         envSetVal("layoutXL" "initDoFolding" 'boolean nil)
         envSetVal("layoutXL" "initDoStacking" 'boolean nil)
         envSetVal("layoutXL" "initCreateMTM" 'boolean nil)
         envSetVal("layoutXL" "initAspectRatioOption" 'string "Height")
         envSetVal("layoutXL" "initAspectRatio" 'float 1)
         envSetVal("layoutXL" "initPrBoundaryH" 'float 1)
         envSetVal("layoutXL" "initUtilization" 'float 35.0)
         envSetVal("layout" "snapPatternDrawingStyle" 'cyclic "tracks")

         hiGetCurrentWindow()~>snapPatternDrawingStyle = "tracks" 

   The examples above are meant to be representative but may not be the correct settings for any particular design flow.

   NOTE: In any design flow, it is important to follow a set/reset model for environment variables. In this way, multiple flows may co-exist in the single environment.
