VALE Framework Component Module:
   Load Gate WSP Templates

Description:
   Loads a SKILL file with WSP definitions using the wspCreateWSP and the wspCreateWSSPDef SKILL procedures.

   Example:

   let((cv)
      cv = geGetWindowCellView()

      ;;**************************
      ;;Poly Pitch: 90n
      ;;Allowed Widths: 18n, 20n
      ;;**************************

      wspCreateWSP(cv "Poly_w18_s72"
          ?offset 0.045
          ?repeatOffset t
          0.018 0.045
      )
      wspCreateWSSPDef(cv "Poly_p90_w18_s72_rgn"
         "Poly" "horizontal" 0.090 ?defaultActive "Poly_w18_s72")

      wspCreateWSP(cv "Poly_w20_s70"
          ?offset 0.045
          ?repeatOffset t
          0.020 0.045
      )
      wspCreateWSSPDef(cv "Poly_p90_w20_s70_rgn"
         "Poly" "horizontal" 0.090 ?defaultActive "Poly_w20_s70")
   )

   In this example, the WSP definition is bound by a let because the geGetWindowCellView() procedure's output is stored in the cv variable.
