VALE Framework Component Module:
   Row-based Termination 

Description:
   This Component Module is part of a row-based design methodology. It uses pattern matching to find locations for automatic creation of "Termination" shapes or structures.  Termination shapes are shapes required around the boundary of some layout, in order to pass DRC.

   Include/RowBasedTermination_V05.xml contains an example topological (squish) pattern definition to do this kind of design data generation.

Setup Requirements:
   - Include/*.conf file: LPA configuration file: set variables compModName, compModVers, and layerOrder. Everything else should stay the same.
   - Include/*.xml: This is an example topological (squish) pattern definition for generating design shapes with the "overlay_scanline_range" parameter.
   - Include/*.streamout_map: A layer map file for writing data from Virtuoso for use in LPA
   - Include/*.lpa_map: A layer map file for reading layout data into LPA for pattern matching
