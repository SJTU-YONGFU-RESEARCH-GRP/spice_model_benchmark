VALE Framework Component Module:
--------------------------------
   Get Shapes from Other Cell, ReStepObjects

Description:
------------
   Steps shapes by a delta, where each subsequent shape is moved to the next
multiple of the delta.

Dependencies:
-------------
   1. A layout file with shapes, and the shapes are expected to be in a single
row or column.  The idea is that you can take a set of poly shapes, or
example, at a 100nm pitch, and change all those shapes to a 200nm pitch, for
example.

Input Requirements:
-------------------
   Open the target cellview, and run this Component Module.  The results will
appear in the current cellview.

Output:
-------
   Moved shapes in the output/current cellview
