VALE Framework Component Module:
   Align Line Ends 

Description:
   This Component Module runs pattern analysis with hotspot fixing to align a set of line ends.  This is just an example, and it is very specific.  Before trying to understand the AlignEnds_V05.xml runset, please review the Cadence Pattern Analysis documentation on "squish" or Topological Patterns on support.cadence.com.

Dependencies:

Input Requirements:
   1. An open cellview in Virtuoso Layout
   2. The special M2 line end structure
