VALE Framework Component Module:
   Row-based Fill

Description:
   This Component Module is part of a row-based design methodology. It leverages Virtuoso Row Templates and Row Regions to automatically mark row objects with a shape on the layers defined in the config file (IMFdefaults.il by default):
   _IMFdat->nRowLpp = list("designFlow" "drawing8")
   _IMFdat->pRowLpp = list("designFlow" "drawing9")

   This module uses the shapes created around the rows to generate the patterned support shapes that a device level layout requires. It may also use:
   _IMFdat->dummyRowLpp = list("designFlow" "drawing5")
   _IMFdat->tapRowLpp = list("designFlow" "drawing6")
   _IMFdat->instRowLpp = list("designFlow" "drawing7")

   After shape generation, any row markers on the layers listed above are removed.

   The module often contains device type markers as well. In addition to passing row type information, the following VALE Framework helper functions are included in the enablement package to create and remove device type markers:
   VALEdeviceTypeMarker(cv "create" "model" "_n1hvt"
      list(list("Nhvt" "drawing")))
   VALEdeviceTypeMarker(cv "remove")
