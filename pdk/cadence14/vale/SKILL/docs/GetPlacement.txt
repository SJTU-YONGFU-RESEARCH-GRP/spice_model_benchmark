VALE Framework Component Module:
--------------------------------
   Save Instance Placement to File, GetPlacement

Description:
------------
   Saves the current cellview's instance placement to a file for use with the
SetPlacement component module.

   The file is VALE_RUNDIR/placementMap.il with the following syntax:

   dbuOld = 2000.0
   placementMapList = list(
      list("T0" list(2.028:2.01 3.022:2.49) "MX")
      list("NINTINV" list(0.425:2.01 1.419:2.49) "MX")
      list("NDUM3(21)" list(7.522:2.01 8.06:2.49) "MX")
      ...
   )

Input Requirements:
-------------------
   1. An open cellview in Virtuoso Layout
   2. One or more instances
