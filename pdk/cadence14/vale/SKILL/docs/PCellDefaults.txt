VALE Framework Component Module:
   Set PCell Defaults 

Description:
   Uses SKILL syntax in the Include/PCellDefaults_V01.il file, to provide a one-button PCell defaults capability. 

Input Requirements:
   An open cellview.  The component module SKILL code will loop through all instances with reference to library _IMFdat->techLib in the config file.
