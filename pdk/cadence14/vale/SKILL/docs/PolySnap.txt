VALE Framework Component Module:
   Snap Instances to Poly WSP Grid

Description:
   Snap instances to the Poly WSP grid.  The instance origins are used to determine which poly WSP to use for snapping. 

Dependencies:
   None

Input Requirements:
   An open cellview.
