VALE Framework Component Module:
   Schematic Design Inventory 

Description:
   This Component Module displays the inventory of cells and parameters for the current design window.  It provides a design tree, instance and cell statistics, and PCell parameter information.

   The configuration file can list the CDF parameters to dump.  The default is alist of the CDF parameters. 

Input Requirements:
   An open cellview.
