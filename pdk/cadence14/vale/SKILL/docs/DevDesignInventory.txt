VALE Framework Component Module:
   Device Design Inventory 

Description:
   This Component Module displays the inventory of PCells and CDF parameters for the current design window, hierarchically.

   The configuration file can list the CDF parameters to dump.  The default is alist of the CDF parameters. 

Input Requirements:
   An open cellview.
