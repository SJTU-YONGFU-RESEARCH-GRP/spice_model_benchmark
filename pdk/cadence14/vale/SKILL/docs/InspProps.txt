VALE Framework Component Module:
   Inspect Schematic Instance Properties

Description:
   This Component Module allows the user to select any schematic that is in edit mode in the current Virtuoso session.  Upon selection of the schematic, all the instances will be listed with their properties.  However, only the properties on the instance that don't correspond to an existing CDF parameter (if the instance is a PCell) will be displayed.

Input Requirements:
   An open cellview.
