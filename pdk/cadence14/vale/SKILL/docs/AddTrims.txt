VALE Framework Component Module:
   Add Trim Shapes

Description:
   Adds a metal trim shape on each colored line end that does not have one.

Input Requirements:
   1. An open layout cell view
   2. A colored metal wire on M1, M2 or M3

Output:
   Colored CutMx shapes on the line ends of the colored metal wires, where x =
1, 2 or 3.
