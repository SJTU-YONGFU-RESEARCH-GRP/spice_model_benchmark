VALE Framework Component Module:
________________________________
   moveVALEModule.txt 

Description
___________
   moveVALEModule allows you to quickly change the moduleNumber for modules. 
   

Dependencies
____________
   Works with default VALE setup.

Input Requirements:
___________________
   Choose from a list of current available module numbers with name and pick a new VALE module number
   to move it to. 

Output:
_______
   Your vale configuration modified to have the module with new configuration number. 
   Menu items are sorted by configuration number so this will change your menu sorting.
