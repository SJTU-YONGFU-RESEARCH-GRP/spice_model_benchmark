VALE Framework Component Module:
--------------------------------
   Schematic Migration, SchMig

Description:
------------
   The Schematic Migration Component Module uses a mapping file in the VALE
Framework Include directory to map PDK devices from one technology to another.

Dependencies:
-------------
   Access to both the source and target PDK in the same Virtuoso session
   NOTE: If the PCell cdfgData~>formInitProc is the same for both PDKs, the
PCell parameter callbacks may not function well. It may be necessary to run
the PCell callbacks again after removing the source PDK from the library
manager.

Input Requirements:
-------------------
   1. A mapping file with a predefined structure
   2. A source cellview based on a source PDK

Output:
-------
   A target cellview in a target library attached to the target PDK

Implementation Details:
-----------------------
   The VALE framework Schematic Migration utility is initialized on Virtuoso
start-up with the following settings in the .cdsinit file:
   setShellEnvVar("CDS_MVS_IMF_CM" "/path/to/VALEframework/install")
   IMFappStart()

   These settings will load the default configuation file:
   $CDS_MVS_IMF_CM/IMFdefaults.il

   For a custom (or project specific) configuration file, add the following
setting to your .cdsinit:
   setShellEnvVar("CDS_MVS_IMF_CONFIG" "/path/to/VALEframework/config.il")

   When a floating point number is compared to an integer (often as a result
of a calculation comparing to an instance's value, the delta that is allowed
to be considered a match is set by the environment variable CDS_MVS_IMF_I2F_DELTA.

   To create a copy of the CIW log and save it as a schMig_<stamp>.log file in
the Virtuoso run directory, use the environment variable CDS_MVS_IMF_SAVE_LOG.
