VALE Framework Component Module:
--------------------------------
   Read Instance Placement from File, SetPlacement

Description:
------------
   Reads a file with instance placement information into the current cellview,
and modifies the placement of the instances based on the file's information.

   The file is in VALE_RUNDIR/placementMap.il with the following syntax:

   dbuOld = 2000.0
   placementMapList = list(
      list("T0" list(2.028:2.01 3.022:2.49) "MX")
      list("NINTINV" list(0.425:2.01 1.419:2.49) "MX")
      list("NDUM3(21)" list(7.522:2.01 8.06:2.49) "MX")
      ...
   )

Dependencies:
-------------
   The instances that exist in the current cellview must have the same
instance names as the file being read. 

Input Requirements:
-------------------
   1. An open cellview in Virtuoso Layout
   2. One or more instances
