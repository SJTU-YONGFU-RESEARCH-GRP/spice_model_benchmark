VALE Framework Component Module:
   Remove VALEfw Properties 

Description:
   When VALE Framework creates shapes, figure groups, or cellviews, it adds a property to each object so that the object may be tracked for later use, such as removal or further processing.  This component module removes all VALE Framework generated properties, not shapes or other objects. It does not save the changes.

   The "Remove" menu item is different.  It removes generated data by selection, whereas this module removes only the property. 

Dependencies:
   None

Input Requirements:
   An open cellview.
