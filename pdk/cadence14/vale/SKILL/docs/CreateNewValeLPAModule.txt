VALE Framework Component Module:
________________________________
   CreateNewValeLPAMoldule 

Description
___________
   CreateNewValeLPAModule creates a new menu item and setups a working PBLO VALE module. 

Dependencies
____________
   Should work with default VALE setup

Input Requirements:
___________________
   Can work to build empty templates, but best used if existing pattern XML file, LPA layer map, and virtuoso layer 
map are available. Can also be setup to use LPA preprocessing deck and PEGASUS rule deck

Output:
_______
   New VALE module configured in you existing VALE setup
