VALE Framework Component Module:
   Add Trim Shapes 2

Description:
   Resolves a complex line end situation with the pattern engine by adding trims and wire extensions.  This is just an example, and it is very specific.  Before trying to understand the AddTrims2_V05.xml runset, please review the Cadence Pattern Analysis documentation on "squish" or Topological Patterns on support.cadence.com.   

Input Requirements:
   An open layout cellview with a special situation of shapes on M2.
