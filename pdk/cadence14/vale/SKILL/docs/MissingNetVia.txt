VALE Framework Component Module:
--------------------------------
   Insert Missing Vias

Description:
------------
   When a net crosses itself without a via, this Component Module adds a via
according to the pattern specification in the Include directory.

Input Requirements:
-------------------
   1. An open layout cellview
