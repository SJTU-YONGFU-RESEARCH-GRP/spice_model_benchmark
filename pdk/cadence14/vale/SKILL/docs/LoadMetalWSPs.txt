VALE Framework Component Module:
   Load Metal WSPs

Description:
   Loads a SKILL file with WSP definitions using the wspCreateWSP and the wspCreateWSSPDef SKILL procedures. 

   Example:

   let((cv)
      cv = geGetWindowCellView()

      wspCreateWSP(cv "M1_w48_s48_template"
         ?shiftColor t
         ?allowedRepeatMode "any"
         ?defaultRepeatMode "stepped"
         0.048 0.096 "color:1"
      )
      wspCreateWSSPDef(cv "M1_p96_w48_s48_region" "M1" "vertical" 0.096
         ?defaultActive "M1_w48_s48_template"
      )
   )

   In this example, the WSP definition is bound by a let because the geGetWindowCellView() procedure's output is stored in the cv variable.

Input Requirements:
   An open cellview.
